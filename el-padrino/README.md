
# El Padrino | Responsive Landing Page Design

A mobile and desktop landing page concept for El Padrino, a Mexican taqueria in Victoria Island, Lagos.

## Problem
Customers of a food business decide quickly. The page needed to show what the restaurant sells, where it is and how to order, with no friction.

## Solution
- Dark theme with a high-contrast amber call-to-action over full-bleed food photography
- Persistent "Order via WhatsApp" button on mobile, so ordering is one tap away
- Location, opening hours and average spend in scannable info cards
- Simplified desktop navigation: Home, Menu, Location, WhatsApp
